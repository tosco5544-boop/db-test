# 全国47都道府県マップ（LP）

## フォルダの中身

```
japan-map-lp/
├─ index.html      … LP本体
├─ css/style.css   … デザイン
├─ js/map.js       … 地図の描画（県名つき）
├─ js/lp.js        … LPの動き
└─ data/checked.js … 地図に色をつける都道府県
```

## 色の変え方

`data/checked.js` を書き換えて、サーバーに上書きしてください。

- `checked` … 行った県（赤）
- `next` … 次に行く県（青）
- `updated` … 最終更新日

例：静岡に行って、次は山口
```
"checked": [22],
"next": [35]
```
